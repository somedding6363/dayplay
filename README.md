# dayplay

매일 하나씩 열리는 미니게임 웹 서비스. 모든 사람이 같은 날 같은 문제를 풀고, 서로의 기록과 비교한다.

## 시작하기

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인한다.

## 명령

| 명령                   | 설명                     |
| ---------------------- | ------------------------ |
| `npm run dev`          | 개발 서버                |
| `npm run build`        | 프로덕션 빌드            |
| `npm run lint`         | ESLint                   |
| `npm run typecheck`    | route 타입 생성 후 `tsc` |
| `npm run format`       | Prettier 적용            |
| `npm run format:check` | Prettier 검사            |
